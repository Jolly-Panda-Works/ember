# 🔥 اخگر (Ember)

**لانچر ویندوزی برای پروژه‌های Node.** یک پوشه اضافه کنید؛ Ember همه‌ی پروژه‌هایی که اسکریپت `dev` / `start` / `serve` / `preview` دارند را پیدا می‌کند، فقط در صورت نیاز پکیج نصب می‌کند و با یک کلیک اجرا می‌کند. اگر کد پروژه‌ای عوض شود، کنارش علامت «بروز شده — تست کنید» می‌آید.

[دانلود](https://github.com/Jolly-Panda-Works/ember/releases/latest/download/Ember-Setup.exe) · [English](README.md) · [گزارش مشکل](https://github.com/Jolly-Panda-Works/ember/issues/new?template=bug_report.yml)

## قابلیت‌ها

| قابلیت | توضیح |
|---|---|
| **پیدا کردن پروژه‌ها** | یک پوشه‌ی پروژه یا پوشه‌ای پر از پروژه را اضافه کنید. |
| **نصب فقط در صورت نیاز** | اگر `node_modules` نباشد یا از lock file قدیمی‌تر باشد، خودکار نصب می‌شود. |
| **دسته‌بندی‌های دلخواه** | به‌طور پیش‌فرض فقط دسته‌بندی «نوع پروژه» هست (وب‌سایت، بازی، موبایل، دسکتاپ، API، سایر). در ⚙️ تنظیمات ← دسته‌بندی‌ها می‌توانید دسته‌بندی بسازید، تغییر نام دهید یا حذف کنید و برای هر کدام مقدار با آیکون و نام اضافه کنید. |
| **لوگوی پروژه** | لوگو یا favicon خود پروژه خودکار پیدا می‌شود، یا تصویر دلخواه را از ✎ ← لوگو انتخاب کنید. در هر دسته‌بندی گزینه‌ی «همه» خودکار است. |
| **پورت جدا برای هر پروژه** | هر پروژه پورت خودش را دارد؛ اگر هنگام اجرا پر باشد، پورت آزاد بعدی انتخاب و به سرور dev داده می‌شود. |
| **اجرا با یک کلیک** | آدرس محلی از خروجی پیدا می‌شود و با 🔗 باز می‌شود؛ لاگ زنده پایین صفحه. |
| **علامت «بروز شده — تست کنید»** | اگر پروژه از آخرین اجرا در Ember تغییر کرده باشد (کامیت جدید یا فایل‌های تازه‌تر)، علامت 🆕 و اعلان ویندوز. با اجرای پروژه یا «✓ تست شد» برداشته می‌شود. |
| **کامیت‌های جدید گیت‌هاب** | هر چند دقیقه `git fetch` (پیش‌فرض ۱۵ دقیقه). اگر کامیتی pull نشده باشد، «⬇ N کامیت جدید» با دکمه‌ی **دریافت**. |
| **تنظیمات** | عمومی (اعلان‌ها، ماندن در System Tray، اجرا با ویندوز)، دسته‌بندی‌ها، بروزرسانی پروژه‌ها، بروزرسانی Ember، دسترسی از موبایل، درباره. |
| **بروزرسانی خودکار برنامه** | هنگام شروع و هر ۶ ساعت GitHub Releases بررسی می‌شود. «دانلود و نصب» نصب‌کننده‌ی جدید را دانلود و اجرا می‌کند. |
| **کنترل از موبایل** | اپ Ember Remote از طریق وای‌فای (با PIN، فقط شبکه‌ی محلی). |

## دانلود

1. **[Ember-Setup.exe](https://github.com/Jolly-Panda-Works/ember/releases/latest/download/Ember-Setup.exe)** را دانلود و اجرا کنید. نسخه‌ی بدون نصب: **[Ember-Portable.exe](https://github.com/Jolly-Panda-Works/ember/releases/latest/download/Ember-Portable.exe)**.
2. «＋ افزودن پوشه پروژه» را بزنید.
3. برای موبایل: **[Ember-Remote.apk](https://github.com/Jolly-Panda-Works/ember/releases/latest/download/Ember-Remote.apk)** را نصب کنید و در ⚙️ تنظیمات ← دسترسی از موبایل، آی‌پی و PIN را ببینید.

## ریلیزها

هر پوش به `main` روی GitHub Actions بیلد می‌شود و خودکار یک **GitHub Release** با شماره‌ی نسخه‌ی `1.0.<شماره‌ی بیلد>` ساخته می‌شود. برنچ‌های دیگر و Pull Requestها فقط بیلد می‌شوند (Actions ← Artifacts).
